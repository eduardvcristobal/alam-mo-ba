# M1.1 — Published Content API

## API
- GET /api/v1/content/facts?mode=student&grade=7&subject=Science&limit=20&offset=0
- GET /api/v1/content/facts/{id}
- GET /api/v1/content/questions?mode=explore&limit=10&offset=0

The list responses contain items, total, limit, and offset. Filter inputs are validated. Database queries use bound parameters. Publishing is fail-closed: only published facts with verified_at, at least one checked source, and an audience mapping appear; questions also require PUBLISHED question status. No demo material is inserted as verified content.

The public question API deliberately excludes correct-answer flags. Server-side attempt grading belongs to a later sub-milestone.

## Run backend
docker compose up -d postgres
cd backend && mvn test && mvn spring-boot:run

## Frontend integration boundary
A typed frontend client and Vite proxy are included on this feature branch. The current approved React prototype has NOT been imported into this empty repository; the downloadable M1.1 package has that baseline. The UI still uses bundled sample content until a verified content set and server scoring exist. Full React-to-API integration, Postgres runtime testing, and real browser E2E are open. Do not treat this feature branch as an end-to-end production release.
