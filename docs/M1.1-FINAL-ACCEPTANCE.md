### M1.1.6 — Content parity

- 36 unique bilingual Grade 7–9 preview fact cards across Science, AP, MAPEH, Math, Filipino, and TLE.
- Nine sample quiz questions with English/Filipino prompts, choices, and explanations.
- Source wording restored from the approved Prototype V2.1 where feasible; math/heritage claims are scoped for correctness.
- Sample data is clearly marked **unverified** and exists only as local fallback. Content is **not** seeded as published content.

### M1.1.7 — Content API integration

- Student and Explore filters query Spring Boot read-only published-content endpoints, with grade/subject settings.
- Verified published facts take priority on the home daily-discovery card; unavailable or empty APIs show labeled sample facts.
- Published facts can be learned/bookmarked as guest (IDs distinguish remote and sample content). Saved remote facts are fetched from the API when viewing bookmarks.
- Server-grade API quiz questions are preferred when available. The frontend never receives answer flags or explanations before submission.

### M1.1.8 — PostgreSQL verification

- Real PostgreSQL 16 starts the Spring Boot app and executes Flyway migrations in CI.
- Synthetic test fixtures include published+verified content, draft content, and unverified content.
- CI asserts published filtering, audience/grade separation, bilingual translations, omission of answer flags, positive and negative scoring, and invalid-answer rejection.
- No CI fixtures are inserted into production or into a developer's real database.

### M1.1.9 — Quiz state and persistence

- Quiz count adjustable from 1–100, automatically capped to the available question bank.
- Repeat preserves question identities. New set prioritizes questions excluded from the previous set; reuses as necessary when exhausted.
- Local guest storage retains completed scores, mode, question IDs, missed IDs, bookmarks, and learned content.
- Working one-use sample 50:50; no lifeline is exposed for server-backed questions until a server-approved protocol exists.
- Cloud account synchronization and server-persisted attempt history belong to M1.2.

### M1.1.10 — Responsive, keyboard, and browser checks

- Skip link, quiz answer pressed state, feedback live announcement, keyboard interaction.
- Chromium checks include 320px horizontal overflow, grade-filter interactions, verified-content bookmarking and reload, quiz replay/new-set, 50:50, and local attempt persistence.

## Known limitations

1. Preview facts are not fact-checked by a teacher/content editor and must not be labeled curriculum-certified.
2. Published content API is currently paginated to the first 100 records in the frontend; future large-bank paging belongs to M2/M3.
3. Guest data resides in browser localStorage; clearing site data removes local progress until cloud sync is developed.
4. Browser acceptance currently executes Chromium only. Safari/WebKit, Firefox, assistive technologies, and external user acceptance remain future gates.
5. Full backend persistence of quiz attempts is deferred to account/guest synchronization work; scoring is server-side for published content.
